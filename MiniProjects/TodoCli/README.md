**Goal:** Build your first useful command-line application.

Create a terminal todo manager that stores tasks in a JSON file.

**Features:**

- Add task
- List tasks
- Mark complete
- Delete task
- Automatically save changes
- Load tasks on startup
- Show task IDs

Example:

```bash
todo add "Buy milk"
todo list
todo done 2
todo remove 2
```

**Learn:**

- Structs
- Enums
- Clap
- Serde
- JSON
- File I/O
- Error handling
